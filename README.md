## 技术栈

- 仅 3 个工具按需加载外部 CDN 库（双 CDN 容错）：
  - 简繁转换 → `opencc-js`
  - Markdown 编辑 → `marked` + `DOMPurify`
  - 二维码 → `qrcode-generator`

## 部署

纯静态站点，推荐 **Cloudflare Pages**（国内访问速度最佳）。

### Cloudflare Pages（推荐）

1. 注册 [Cloudflare](https://dash.cloudflare.com/) → Workers & Pages → 创建应用程序 → Pages → 连接 Git
2. 授权 GitHub，选择仓库 `weipu2026/114-tools`
3. 构建设置：
   - **构建命令**：留空（无需构建）
   - **输出目录**：`/`
4. 点击部署，完成后在自定义域中绑定 `114448.xyz`
5. 每次 `git push` 到 `main` 分支自动部署

> 优势：全球 330+ CDN 节点，中国大陆有合作节点，自带 HTTPS，无限带宽。

### GitHub Pages

`Settings → Pages`，Source 选 `main` 分支根目录。适合海外访问或 demo 展示。

### Netlify / Vercel

同 Cloudflare Pages，构建命令留空，输出目录 `/`。

### Nginx / OSS / 对象存储

直接把整个目录上传即可，无任何后端要求。

> ⚠️ `sitemap.xml` 中站点地址默认写的是 `https://114448.xyz`，若域名有变化请同步修改。
